# 🚀 Real News

## 💡 Sobre o Projeto
Foi um projeto apresentado em um evento "IDEATHON" organizado por alunos e professores
da Uninassau. O projeto funciona como um indetificador de Fake News, podendo colocar 
arquivos, links, imagens e documentos e fazendo assim o site identificar se o que você 
colocou é veridico ou falso.

---

## 🛠️ Tecnologias Utilizadas

As principais ferramentas e tecnologias usadas no desenvolvimento do projeto:

* **Linguagem:** Java, Python, CSS e HTMl
*  Também foi utilizado uma API do gemini que consegue buscar as fontes do que você
 enviou.
